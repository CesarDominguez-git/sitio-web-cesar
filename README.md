#QUE CONTIENE EL PROYECTO
El proyecto contiene un panel de administrador en el que puede gestionar usuario, gestionar tareas, gestionar proyectos, gestion de clientes y reportes en pdf.

#COMO ABRIRLO
Descargamos el archivo.zip, abrimos Vscode y seleccionamos la carpeta, luego ejecutamos el Apache y MySQL en XAMPP y finalmente en el navegador pondremos el localhost

#QUE APRENDISTE
Cómo organizar un sitio web en carpetas.
Cómo documentar un proyecto con un archivo `README.md`.
Cómo subir proyectos a GitHub y mantenerlos con commits.
